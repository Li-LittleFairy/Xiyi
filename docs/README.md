# 文档总入口

本目录建立于 2026-11-18，2026-11-19 整理为分类结构。仓库内的 Word 文档（`.docx`）与 Markdown 文档（`.md`）统一存放在本目录，代码目录只保留代码与脚本，不再放置说明文档；`AGENTS.md` 因需被工具从仓库根目录读取而留在根目录。

当前按本机开发演示推进，正式部署之后确定；正式业务范围尚未全面确认。

## 目录结构

| 目录 | 放什么 |
| --- | --- |
| `01-需求与来源材料/` | 需求说明书、领导版业务简报、对话归档、开发准备大纲等来源材料 |
| `02-开发文档/` | 业务边界、流程推演、数据模型、开发环境等当前在用的开发文档 |
| `03-ADR/` | 重要技术决定及其状态 |
| `04-组件说明/` | 数据库脚本与展示原型的说明文档 |

下表中的路径相对 `docs/` 目录；脚本、代码和原型页面仍在各自原位。

## 后续随工作形成的材料

1. 首版范围、角色权限及业务规则：包含来源、结论和验收示例。
2. 数据模型和数据库迁移：表、关系、约束、价格与收款记录的保存方式。
3. 接口契约：请求、响应、权限、校验失败及重复请求处理。
4. 环境版本和启动说明：实际验证后的 JDK、构建工具、数据库及前端工具版本。
5. 验收与备份恢复说明：可重复执行的步骤及验证结果。

这些材料按功能逐步补充，不需要先写完大而全的文档才能开始技术验证。
