# 架构决策记录（ADR）

ADR 用于记录影响较大的技术取舍：当时的问题、备选方案、选择理由和后果。它不是一般任务清单，也不替代业务确认。

## 使用方式

- 新决策使用 `template.md`，依序编号；只有重要取舍才新增 ADR。
- 状态包括：提议中、已采纳、已否决、已被替代。
- 已采纳记录应注明依据和决定人；AI 的建议不自动成为已采纳决定。
- 后续改变重要决定时新增替代记录，在旧记录中标注关联，不覆盖历史原因。
- 用户已经明确授权的范围内，普通实现细节可直接推进；ADR 不要求每次改代码再次审批。
