# ADR-0001：本机开发演示与正式部署分阶段确定

- 状态：已采纳
- 日期：2026-11-18
- 决定人：项目用户
- 依据：用户明确选择“先在本机开发演示，正式部署之后确定”。

## 背景

当前已有双端展示原型，后续将开展真实后台和数据库开发。正式产品访问范围及部署环境尚未明确，不宜将云资源或公网访问提前作为前提。

## 考虑的方向

1. 先本机开发演示，随后确定正式部署。
2. 直接围绕店内电脑或局域网部署。
3. 直接围绕顾客公网手机访问部署。

## 决定

采用方向 1。当前开发服务与数据库可以部署在同一台开发电脑。具体数据库方案另见 ADR-0002。

## 后果与边界

- 目前不需要购买云服务器；本决定不授权购买或对外发布。
- 本机开发仍需真实后端、持久化存储和可重复启动配置。
- 双端在本机演示，不意味着已经具备跨设备访问或正式顾客认证能力。
- 正式访问方式确定后重新评估部署、数据库及身份认证需求；不承诺迁移零成本。

## 验证方向

在本机启动浏览器和后端，完成数据库写入与查询，并在服务重启后确认数据保留。后续业务按独立验收清单验证。
