# 拾净洗护界面与功能清单

本清单对应 V0.3 可点击原型，用于说明界面承载的功能。

## 顾客端

| 编号 | 界面 | 展示功能 |
| --- | --- | --- |
| C01 | 首页 | 服务分类、送洗入口、最近订单 |
| C02 | 洗护服务 | 查看项目与单价，选择衣物项目 |
| C03 | 预约送洗 | 调整件数，填写联系信息、送店日期与特别说明，查看预估费用并提交 |
| C04 | 我的订单 | 进行中、已完成、全部订单筛选 |
| C05 | 订单详情 | 洗护进度、衣物明细、订单费用、收款状态、预计取衣日期 |
| C06 | 个人信息 | 修改姓名和手机号，快捷进入订单列表 |

## 门店端

| 编号 | 界面 | 展示功能 |
| --- | --- | --- |
| M01 | 门店工作台 | 今日新增、处理中、待取衣、今日实收、最新订单、待办事项 |
| M02 | 收衣开单 | 登记客户，添加衣物及件数，记录已有瑕疵，计算费用，填写取衣日期并确认收衣 |
| M03 | 订单管理 | 状态筛选，订单号、客户姓名、手机号搜索 |
| M04 | 订单详情 | 对顾客送洗需求确认实际收衣，核对件数和衣物状况，查看费用、服务信息与操作记录 |
| M05 | 洗护任务 | 分列查看待洗护、洗护中、待取衣任务，开始洗护或确认洗护完成 |
| M06 | 取衣交付 | 选择待取衣订单，核对客户与衣物，登记线下收款，确认交付 |
| M07 | 客户管理 | 客户联系方式、送洗次数、累计实收、最近送洗日期、历史订单 |
| M08 | 经营统计 | 累计实收、订单量、完成量、未收金额、近七日实收、项目件数分布、收款流水 |
| M09 | 基础设置 | 修改项目单价，添加店员，启用或停用店员账号 |

## 双端订单流程

顾客提交送洗需求 → 门店核对并确认实际收衣 → 开始洗护 → 洗护完成 → 登记收款 → 确认衣物交付。

顾客端可以查询门店处理后更新的状态和费用。门店直接开单时从确认收衣开始。项目价格调整用于新订单；已确认收衣的订单保留成交价格，顾客预下单的费用在实际收衣时核对。

## 原型数据

所有操作仅更新当前浏览器的展示数据，不会向实际门店发单，也不会执行真实支付。清单描述原型所展示的功能；正式开发范围仍以之后的业务讨论结果为准。
