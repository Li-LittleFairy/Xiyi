# 拾净洗护双端展示原型 V0.3

解压后，直接用浏览器打开 `laundry-prototype/dist/index.html`（路径相对仓库根目录）。顶部可以切换「顾客端」「门店端」「页面总览」。不需要安装程序。

## 推荐展示顺序

1. 打开「页面总览」，了解顾客端 6 个界面和门店端 9 个界面，以及各自包含的功能。
2. 在顾客端进入「预约送洗」，选择衣物与件数，填写联系信息后提交。
3. 切换门店端，在「订单管理」找到该订单并进入详情，核对实际件数、衣物状况、预计取衣日期，确认收衣。
4. 在「洗护任务」中开始洗护，完成后移入待取衣。
5. 在「取衣交付」登记收款，勾选已核对客户和衣物，确认交付。
6. 返回顾客端「我的订单」，查看同一笔订单的完成状态和费用信息。

员工也可以通过「收衣开单」直接建立柜台订单。门店端还包含客户历史记录、经营统计、项目价格和员工账号管理。

## 文件说明

- `laundry-prototype/dist/index.html`：统一入口。
- `界面与功能清单.md`：按界面列出的展示功能（与本说明同目录）。
- `laundry-prototype/dist/customer.js` 与 `laundry-prototype/dist/customer.css`：顾客界面。
- `laundry-prototype/dist/store.js` 与 `laundry-prototype/dist/store.css`：门店界面及双端切换。

数据保存在当前浏览器，两端在同一个页面中切换，因此可以同步展示订单变化。人员、品牌、价格与订单样例用于交互展示；没有真实后台、支付接口或身份认证。展示功能不等于已经批准的开发范围。
