## 环境事实与执行前提

- 已核验服务端MySQL 8.0.44、端口3306及严格SQL模式；使用本机xiyi登录配置，以root@localhost创建xiyi_dev。应用专用账号尚未配置。
- 脚本目标为支持强制执行 CHECK 的 MySQL 8.0.16+，使用 InnoDB、utf8mb4。执行前检查服务端版本和 SQL 模式，使用严格模式避免字段被静默截断。
- 当前项目库为xiyi_dev，已经执行V001，不要重复运行。后续结构变更使用新的迁移；不要在其他项目或正式业务库执行本项目脚本。
- 不在对话、脚本或仓库中填写密码。应用账号与建表/迁移权限应分开管理。

## 脚本性质

脚本无 CREATE DATABASE、USE、DROP、TRUNCATE、默认管理员或密码，也不修改全局配置。执行者必须显式选择目标库。表已存在时应停止并核对迁移记录，不能用 IF NOT EXISTS 掩盖结构差异。

MySQL 的 CREATE TABLE 会隐式提交，整份脚本不是可整体回滚的事务；中途失败时可能已有部分表创建成功。应核对已执行部分并制定恢复步骤，不得自动删除现有表。后续工程需要选定迁移执行工具并记录版本；文件使用 V001 编号不代表已接入某个工具。
