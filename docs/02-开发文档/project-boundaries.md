## 2. 当前交付方向

在一台开发电脑上运行真实后端和持久化存储，逐步实现已明确范围内的业务，并用本机浏览器演示。正式开发完成哪些业务，应以随后形成的首版范围和验收清单为准。

当前原型只使用浏览器展示数据，不能替代数据库、后端权限或真实部署验证。保留原型便于比较交互和说明功能。

## 4. 本阶段的工程约束

- 本机开发和虚构数据优先；当前没有购买服务器、上线服务或连接正式业务数据的任务。
- 不默认引入 Redis、消息队列、微服务、容器编排等组件；有具体需求时记录理由和代价。
- 正式业务实现由后端验证身份权限、计价及状态，不能信任前端传来的身份、价格或付款结论。
- 金额采用明确精度或最小货币单位处理；记录成交价格；订单、收款和操作历史应保持一致。
- 关键动作需要防重复；设计数据库变更、备份和恢复方式，并验证恢复结果。
- 一份文件负责一种事实：技术取舍以已采纳 ADR 为准，业务范围以业务决定记录为准；发现冲突时说明并修订。

以上工程约束用于保障实现质量，不代表收费时点、取消资格或会员规则已经确定。
